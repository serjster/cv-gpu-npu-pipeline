# No Agent Attribution

## Code Comments

Never add comments in code that reference Claude, Copilot, Opencode, AI, or AI-generated content. Examples of what NOT to write:

- `// Generated by Claude`
- `// AI-assisted`
- `# Added by Claude Code`
- Any variation attributing code to Claude or AI

## Git Commits

Never include "Co-Authored-By: Claude" or any similar AI attribution lines in git commit messages.

## Rationale

All code should read as if written by the developer. Attribution to AI tools is unnecessary noise.
